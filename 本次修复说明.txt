ísmolar 同声传译 v1.9.25｜简洁界面版

本版变化
====================

- 修复 OpenAI 模式“识别正常但没翻译”：翻译结果之前只更新了内部段落，
  没有写入字幕显示流，导致浮窗一直不出译文。现在译文正确上屏，
  并新增“翻译结果”日志便于排查；空译文不再写入翻译记忆。

上一版（v1.9.24）
====================

- 修复中文识别时模型用词条表“编造宣传句”的幻觉（如
  “BIOEFFECT蓓欧菲大麦生长因子护肤品牌”）：词条字符占整句
  比例过高即整段丢弃；再次清空被污染的翻译记忆缓存。

上一版（v1.9.23）
====================

- OpenAI 模式网络抖动自动重试（SSL/连接中断等最多重试 3 次）；
- 识别结果一句话混入 ≥3 个词条项时判为噪声幻觉（模型脑补），
  整段丢弃，不再进字幕和翻译记忆。

上一版（v1.9.22）
====================

- OpenAI 模式识别模型默认切换为 gpt-4o-transcribe（词错率更低、
  品牌/人名/多语言更准），翻译仍用 gpt-4o-mini。

上一版（v1.9.21）
====================

- OpenAI 模式提速：去掉 6 秒硬限速（改为只防连发 1 秒），
  分段时间从 4.5 秒缩短到 3 秒；真撞 429 限流时自动等 6 秒重试。
  充值后账号限流自动放宽，字幕响应会明显加快。

上一版（v1.9.20）
====================

- 清空被污染的翻译记忆缓存（旧版提示词回显的脏数据），
  并加防护：带提示词残留的识别/翻译结果不再写缓存；
  系统提示词改用真实换行，避免 gpt-4o-mini 把词条表拼进译文；
  极短文本同时混入多个词条（如“BIOEFFECT蓓欧菲”）判为回显丢弃。

上一版（v1.9.19）
====================

- 修复 OpenAI 模式“识别结果回显提示词”：转写模型在静音/背景噪声时
  会把我们给它的引导词原样输出成字幕。现在提示词改为纯词表、
  静音缓冲不送识别、识别到提示词内容直接丢弃。

上一版（v1.9.18）
====================

- 浮窗侧边工具栏不再自动隐藏，“停止”按钮常驻可见，
  避免同传过程中找不到停止按钮。

上一版（v1.9.17）
====================

- OpenAI 模式修复新账号限流（429 RPM 10）：
  识别请求限速为 6 秒一次（自动保证每分钟不超过 10 次），
  遇限流自动等 6 秒重试最多 3 次；分段时间调整为 4.5~9 秒，
  避免短句连发触发账号级限流。

上一版（v1.9.16）
====================

- OpenAI 模式精简：去掉未启用的临时字幕与转录缓存逻辑，
  字幕按句（约 3~7 秒）更新，识别成本不重复计费。

上一版（v1.9.15）
====================

- 新增第三种运行模式“国外模式（OpenAI 识别+翻译）”：
  gpt-4o-mini-transcribe 负责识别（支持把固定词条写进识别提示，
  品牌词第一次就能认对），gpt-4o-mini 负责翻译，全程走 OpenAI，
  冰岛/海外延迟低，不需要国内接口；
- 接口设置里可分别选择识别模型与翻译模型（默认
  gpt-4o-mini-transcribe + gpt-4o-mini），填一把 OpenAI API Key 即可；
- 固定翻译、模糊纠错、翻译记忆在 OpenAI 模式下同样生效。

上一版（v1.9.14）
====================

- 固定翻译新增“模糊纠错”：识别结果里只要出现和词条足够相似的片段
  （例如 Byo Effect / Bio Efect / Bell Efect 之于 BIOEFFECT），会自动
  替换成标准词条再翻译，不需要先把听错的变体手动录入词条。
  别名词条（Belle Effect 等历史听错）会自动归一化到主词条；
  阈值保守，普通句子（如 good effect / growth rate）不会被误替换。
- 修复词条替换逻辑：之前英文片段正则会把整个句子吞成一个片段导致
  译文里的品牌词替换不生效，现已按词边界匹配（BIOEFFECT 可匹配
  Bio Effect / bio-effect，但不会误吞整句）。
- 版本号提升到 v1.9.14，便于区分新旧包。

上一版（v1.9.13）
====================

- 接口设置里的 API 密钥（讯飞 APIKey / APISecret、DeepSeek API Key）
  改为明文显示，输入和核对时不再被隐藏。

上一版（v1.9.12）
====================

- 修复网络断线导致会话直接终止的问题（如 Wi-Fi 抖动、防火墙/代理/VPN
  中断、ping/pong 超时）：现在会自动重连最多 3 次，重连后从断点继续，
  已识别的会议内容不丢失，无需重新开始。

上一版（v1.9.11）
====================

- 导出 Word 文档不再使用表格：每一段改为“中文在上、英文在下”的段落对照，
  段号与语言标签加粗，段落之间留空行；TXT 导出保持同样格式。

上一版（v1.9.10）
====================

- 浮窗设置里的字号输入框改为苹果风格：数值 + 圆形 − / + 步进按钮，
  不再使用系统箭头；
- 字幕颜色、描边颜色改为苹果风格圆形色块 + 十六进制值显示，
  点击色块打开系统取色器，按下时有蓝色高亮反馈。

上一版（v1.9.9）
====================

- 字幕字体固定为微软雅黑，不再提供其他字体选项；
- 新增“字重”选择：常规 / 中等 / 加粗，直接作用于字幕显示。

上一版（v1.9.8）
====================

- 修复字幕浮窗无法缩放的问题：浮窗是无边框窗口，系统缩放把手不可靠，
  现在手动实现了四边 + 四角缩放，鼠标移到边缘会显示双箭头光标，
  直接拖拽即可调整浮窗大小，macOS / Windows 行为一致。

上一版（v1.9.7）
====================

- 修复新机器首次运行的问题：Application Support 目录不存在时，
  翻译记忆磁盘层此前会静默失效，现在自动创建目录后正常启用。
- 翻译记忆数据库权限收紧为仅本人可读写（macOS 600）；
  Windows 走 %APPDATA% 的账户私有权限，无需额外设置。
- Windows 同步测试版同步更新到 v1.9.7，GitHub Actions 产物名修正。

上一版（v1.9.6）
====================

- 翻译记忆升级为“内存热缓存 + 磁盘持久化”两级：
  内存热缓存满 800 条时，先把最旧一批自动存盘再腾位置，新译文不再被丢弃；
  查找时先查内存、未命中再从磁盘加载精确条目并放回热缓存；
  磁盘记忆保存在“Application Support/ismolar-interpreter/manuscript_memory.db”，
  跨会话保留，下次开会直接复用，不再受单次会议条数限制。

保留功能（沿用 v1.9.x）
====================

- 中英文混合识别（自动方向）
- DeepSeek 英译中 / 讯飞同传中译英
- 固定翻译（术语表）与参考稿件
- 稳定字幕模式：区间内后台修正，结束时一次性追加，历史字幕不重写
- 停止后自动补译与中英对照文档（Word/TXT 保存）

测试
====================

1. 运行“②先测试功能.command”做源码测试，或双击“①一键制作DMG.command”打 DMG；
2. 选择“自动”方向，依次说中文、英文，观察字幕与最终文档；
3. 连续说 5 句英文后停止，确认 5 句译文全部出现在文档中。
